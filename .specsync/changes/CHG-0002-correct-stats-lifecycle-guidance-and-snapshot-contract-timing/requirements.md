# Requirements

- Correlation guarantees must apply only to response-bearing protocol operations.
- Snapshot store messages must be documented as fire-and-forget.
- Snapshot ordering must match the implemented load, calculation, store, and output sequence.
- Agent integrations must preserve complete natural-language input before deriving commands or module names.
- SDD verification must invoke the native Fledge lane and govern published documentation and agent files.
